# Change proposals

One file per change to the product or scope, written **before** the docs are edited. Together they're the history of why the plan looks the way it does.

- Start one with `/sync-docs [the change]` in Claude Code, or copy `0000-template.md` to `<YYYY-MM-DD>-<short-name>.md`.
- Technical decisions (libraries, architecture) go in `docs/decisions/` instead.
