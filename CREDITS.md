# Credits

The workflow comes from the talk **"Think First, Then Build"** by DevCon Dave (Edmonton Unlimited, September 2026).

Several skills and rules here were written for this template but inspired by ideas from these open-source projects (all MIT-licensed). No files were copied; any mistakes are ours.

|---|---|

| `tdd`, `fix-bug`, `prove-it` skills | [obra/superpowers](https://github.com/obra/superpowers): test-driven development, systematic debugging, verification before completion |
| `grill-me`, `handoff` skills | [mattpocock/skills](https://github.com/mattpocock/skills): grill-me, handoff |

| Interview guide | *The Mom Test* by Rob Fitzpatrick |
